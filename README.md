# 🎬 Content-Based Movie Recommendation System using NLP

## Project Overview

This project develops a **Content-Based Movie Recommendation System** using Natural Language Processing (NLP) techniques. Instead of relying on user ratings or collaborative filtering, recommendations are generated by comparing movie metadata such as genres, keywords, plot overview, cast members, and directors.

The project demonstrates an end-to-end machine learning workflow including data preprocessing, feature engineering, Bag-of-Words vectorization, and similarity computation using Cosine Similarity.

---

## Business Problem

Modern streaming platforms contain thousands of movies, making it difficult for users to discover relevant content.

The objective of this project is to build a recommendation engine capable of suggesting movies with similar characteristics based solely on movie content.

## Project Workflow

1. Import datasets
    
2. Exploratory Data Analysis (EDA)
    
3. Merge movie and credit datasets
    
4. Handle missing values
    
5. Feature selection
    
6. Parse JSON-like columns using `ast.literal_eval()`
    
7. Extract
    
    - Genres
        
    - Keywords
        
    - Top Cast Members
        
    - Director
        
8. Clean textual features
    
9. Remove spaces from multi-word entities
    
10. Combine all text into a single feature
    
11. Generate Bag-of-Words representation
    
12. Calculate Cosine Similarity
    
13. Recommend Top 5 similar movies
    

---

## Data Cleaning

The following preprocessing steps were performed:

- Removed duplicate columns after merging datasets
    
- Handled missing values
    
- Converted release dates into year format
    
- Selected relevant recommendation features
    
- Parsed nested JSON strings using Python's `ast.literal_eval()`
    
- Extracted genre names
    
- Extracted keywords
    
- Extracted top five cast members
    
- Extracted movie directors
    
- Removed spaces from names to preserve entity meaning during tokenization
    

Example

```
James Cameron
↓

JamesCameron
```

---

## Feature Engineering

A new feature called **context** was created by combining:

- Genres
    
- Keywords
    
- Movie Overview
    
- Top Cast Members
    
- Director
    

This single text representation captures the semantic characteristics of each movie.

---

## NLP Pipeline

The recommendation engine uses a classic NLP pipeline:

- Text Cleaning
    
- Tokenization
    
- Bag-of-Words (CountVectorizer)
    
- Stop-word Removal
    
- Maximum Vocabulary Size = 5000
    
- Sparse Matrix Representation
---

## Recommendation Engine

After vectorization, Cosine Similarity computes pairwise similarity between every movie.

Movies with the highest similarity scores are returned as recommendations.

Example

```
Input

Titanic

Recommendations

Captain Phillips
The Notebook
In the Heart of the Sea
Ghost Ship
The Bounty
```
